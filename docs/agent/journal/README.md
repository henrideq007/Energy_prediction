# Agent journal

One file per run: `YYYY-MM-DD.md` (add `-2`, `-3` if several runs happen the same day).
Written in English, short, factual. Template:

```markdown
# Run YYYY-MM-DD

- **Task:** T<ID> — <title> (Notion link)
- **Branch / PR:** agent/T<ID>-slug — <PR link>
- **Outcome:** done | partial | blocked | nothing to do
- **What changed:** 2–5 bullets
- **Results (if any):** metric table or link to Experiments & Results row
- **Reviewer verdict:** approve | changes needed (summary)
- **Questions for Henri:** …
- **Suggested next step:** …
```
